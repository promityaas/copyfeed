# Copyfeed download

Download `copyfeed-v0.16.0.zip`, extract it to a permanent folder, and load that folder through Chrome → Extensions → Developer mode → Load unpacked.

This is the v0.16.0 release candidate. Automated checks pass, but installed-extension and live-platform validation remain pending. See `docs/TEST_RESULTS.md` and `docs/FEATURES.md` in the repository.

`SHA256SUMS` records the extension archive checksum. Source and reproducible build instructions are in the repository root.
